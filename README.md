# 아두이노 우노 R4 · LED 회로 3D 시뮬레이션

아두이노 우노 R4 WiFi의 5V 핀, 저항 220Ω, 빨간 LED, GND 핀으로 이루어진 회로에서 **전류의 흐름, 전자의 흐름, 저항에 의한 전압강하**를 보여 주는 수업용 3D 시뮬레이션입니다.

- 실행 파일: [index.html](index.html) (브라우저에서 바로 열림, 인터넷 연결 필요)
- 제작에 쓴 프롬프트: [PROMPT.md](PROMPT.md)

## 조작법

| 조작 | 동작 |
|---|---|
| `←` `→` 키 또는 이전/다음 버튼 | 설명 단계 이동 |
| 속 보기 / 겉 보기 | 부품을 투명하게 해 도선 속 전자를 보여 줌 |
| 분해하기 / 다시 합치기 | 부품을 떼어 브레드보드 내부 금속 클립을 보여 줌 |
| 전류 / 전자 / 둘 다 | 전류 화살표와 전자 입자를 골라 표시 |
| 전압 보기 | 도선을 전위 색으로 표시 (5V 빨강, 2V 주황, 0V 파랑) |
| 마우스 올리기 | 부품 이름과 설명 |
| 드래그 / 휠 | 회전 / 확대·축소 |

## 설명 단계

1. 닫힌 길
2. 전류의 방향
3. 전자의 이동
4. 저항에서의 전압강하
5. LED에서의 전압강하
6. 정리 (3.0V + 2.0V = 5V)

## 수치

전원 5V, 빨간 LED 순방향 전압 약 2.0V, 저항 220Ω 기준으로 전류는 약 13.6mA입니다. 전자의 움직임은 이해를 돕기 위해 과장해 표현했습니다.
